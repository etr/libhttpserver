1. [ ] **performance-reviewer** | `src/detail/http3_qpack.cpp:75` | algorithmic-complexity
   The whole encoder instruction decoder is rerun after each byte. A complete Huffman literal name is scanned again while its value is incomplete, giving O(encoded_name_bytes * encoded_value_bytes) parsing work for one valid instruction, even when delivered in one coalesced feed call. The default 4096-byte instruction-limit probe measured 32 inserts at 512/1024/2048 decoded bytes per name/value as 38.743/151.901/607.861 ms; roughly doubling the input quadruples time. Corresponding plain strings at 512/1024 bytes took 0.746/1.441 ms. The largest Huffman instruction was 2822 wire bytes and repeated successfully with admitted table capacity 8192. This unnecessarily occupies the serialized connection owner despite bounded memory and instruction count.
   *Recommendation:* Track instruction phase and expected extent incrementally, caching completed Huffman-name validation or deferring complete string inspection until the instruction extent is available. Keep table mutation atomic and use a bounded regression/probe to verify near-linear work across sizes and fragmentation.

2. [ ] **security-reviewer** | `src/detail/http3_qpack.cpp:75` | resource-exhaustion
   CWE-407: qpack_input invokes the complete instruction decoder after every received byte. Once an Insert With Literal Name Huffman name is complete, qpack_inspect_string walks that whole name again for every subsequent value byte. A peer in admitted dynamic mode can repeatedly send valid 2822-byte instructions with 2048-byte names and values: 32 took 607.861 ms in the linked local probe, within the default 4096-byte instruction bound. This keeps the serialized protocol owner occupied with quadratic attacker-controlled work even when memory and completed-instruction counts stay bounded. The default zero-capacity mode rejects the insertion at completion, so sustained valid repetition requires admitted nonzero dynamic capacity.
   *Recommendation:* Keep incremental wire length/phase state or cache admission of the completed literal name so later value bytes do not repeat its Huffman walk. Preserve atomic table mutation at instruction completion. Add a bounded regression that demonstrates each completed Huffman name is validated once across fragmented/coalesced input.
